# Croșetăm — „Tutoriale de croșetat pas cu pas, în română”

Romanian crochet DIY blog at **crosetam.getemoji.site**. Every article is an original, step-by-step written guide
built around one Romanian YouTube tutorial (embedded, creator credited + linked). WordPress on Docker (Coolify),
fully set up on first start — no wp-admin clicks needed.

## What's inside
- `wp-content/themes/viral-reader` — parent theme (vendored, v1.9.34, + `languages/ro_RO`)
- `wp-content/themes/crosetam` — brand child theme: Fraunces headings (self-hosted, Romanian diacritics), crochet
  palette, tutorial card (level / time / video creator), click-to-play YouTube facade + VideoObject schema,
  share (Facebook / WhatsApp / Pinterest) + next tutorial, sticky next-tutorial bar, dark mode
- `wp-content/plugins/automation-hamri` — publishing/SEO/ads engine (vendored, v9.42.0)
- `data/bundles/*.zip` — article bundles (`posts.json` + `images/`), imported once each on start
- `seed/seed.php` — brand, Romanian pages, categories, menus, AdSense Auto ads, import (idempotent, resumable)
- `docker/site-init.sh` — waits for DB, syncs theme/plugin, installs WP + ro_RO once, runs the seed

## Adding articles
Drop a new `data/bundles/crosetam-NN.zip` (same format) → commit → push → Coolify Redeploy. Already-imported
bundles are skipped; new ones are published and internally linked automatically.

## Coolify
Docker Compose build pack, domain on the `wordpress` service. Env vars generated by Coolify:
`SERVICE_FQDN_WORDPRESS_80`, `SERVICE_USER_MYSQL`, `SERVICE_PASSWORD_MYSQL`, `SERVICE_PASSWORD_MYSQLROOT`,
`SERVICE_PASSWORD_WPADMIN`. Optional: `ADSENSE_CLIENT` (`off` disables ads), `WP_ADMIN_EMAIL`.

Admin login: `/wp-admin`, user `redactia`, password = Coolify's `SERVICE_PASSWORD_WPADMIN`.
